# Analise-de-dados-em-Python
Analise da dados sobre as rede socias: Instagram,TikTok,WhatsApp e Youtube
# Redes Sociais no Brasil 📱

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de entender um pouco melhor como as redes sociais fazem parte do dia a dia dos brasileiros. Para isso, escolhi analisar quatro plataformas bastante conhecidas: **TikTok, Instagram, WhatsApp e YouTube**.

A ideia foi reunir dados sobre o público dessas redes e organizar as informações de uma forma visual, facilitando a comparação entre elas. Durante a análise, procurei observar aspectos como faixa etária, distribuição por sexo, diferenças entre as regiões do Brasil, horários de uso e tempo que as pessoas passam nas plataformas.

## O que foi analisado?

Cada rede social possui características próprias, e a análise ajuda a perceber algumas dessas diferenças.

- **TikTok:** perfil do público e horários em que a plataforma é mais utilizada.
- **Instagram:** distribuição dos usuários por idade e sexo, além de informações sobre os horários de acesso.
- **WhatsApp:** dados relacionados ao uso de mensagens instantâneas e à frequência de utilização.
- **YouTube:** informações sobre o consumo de vídeos e os períodos de maior utilização.

Os resultados são apresentados em gráficos e em um dashboard interativo, que permite visualizar os dados de cada rede separadamente.

## Tecnologias utilizadas

Para desenvolver o projeto, utilizei Python e algumas bibliotecas que ajudaram a organizar os dados e criar os gráficos:

- **Python:** linguagem utilizada para desenvolver a análise.
- **Pandas:** organização e manipulação dos dados.
- **NumPy:** operações e cálculos com os valores.
- **Matplotlib:** criação dos gráficos.
- **Seaborn:** personalização e apresentação dos gráficos.
- **HTML e CSS:** estrutura e aparência do dashboard.

## Como executar o projeto

Para executar o código no seu computador, é necessário ter o Python instalado.

**1.** Baixe ou clone este repositório.

**2.** Abra o terminal na pasta do projeto.

**3.** Instale as bibliotecas necessárias com o comando:

```bash
pip install -r requirements.txt
```

**4.** Execute o arquivo Python:

```bash
python analise_redes_sociais.py
```

Depois da execução, o programa gera dois arquivos: `index.html`, que contém o dashboard, e `dados_redes_sociais.csv`, que reúne os dados utilizados na análise.

Para visualizar os resultados, basta abrir o arquivo `index.html` em um navegador.

## Fontes dos dados

Os dados foram reunidos a partir de relatórios, pesquisas e plataformas que publicam informações sobre o uso das redes sociais e o comportamento dos usuários no Brasil.

Entre as principais fontes utilizadas estão:

- [DataReportal — Digital 2026: Brazil](https://datareportal.com/reports/digital-2026-brazil)
- [Cetic.br — TIC Domicílios 2025](https://cetic.br/)
- [NapoleonCat — usuários de redes sociais no Brasil](https://stats.napoleoncat.com/social-media-users-in-brazil/)
- [Affect Group — dados sobre o público do TikTok](https://affectgroup.com/blog/brazil-tiktok-audience-by-age-and-gender/)
- [Opinion Box](https://www.opinionbox.com/)
- [mLabs — comportamento da audiência digital](https://www.mlabs.com.br/blog/comportamento-da-audiencia-digital/)

Também foram utilizadas publicações do Canaltech e da Teletime para complementar algumas informações.

**Observação:** as fontes não utilizam necessariamente o mesmo período, método de pesquisa ou definição de público. Por isso, os resultados devem ser interpretados considerando essas diferenças.

Em alguns gráficos, foram utilizados indicadores aproximados (*proxies*), pois nem sempre existem dados públicos específicos para cada rede social e cada grupo analisado. Esses indicadores não devem ser interpretados como medidas diretas de utilização de uma plataforma específica.

## O que foi possível perceber?

A análise mostra que as redes sociais podem apresentar diferenças no perfil do público, na frequência de utilização e nos horários de acesso. Também foi possível organizar essas informações de maneira visual, facilitando a observação dos dados e a comparação entre as plataformas.

Outro ponto importante foi perceber que nem todos os dados disponíveis podem ser comparados diretamente. Algumas informações se referem a usuários de uma plataforma específica, enquanto outras representam hábitos mais gerais de utilização da internet.

Por isso, além de observar os gráficos, é importante considerar as fontes e as limitações de cada indicador antes de tirar conclusões.

## Conclusão

Desenvolver este projeto foi uma oportunidade de praticar a análise de dados com Python e entender melhor como transformar informações de diferentes fontes em gráficos e visualizações.

Além da parte de programação, o trabalho também mostrou a importância de pesquisar as fontes, organizar os dados e interpretar os resultados com cuidado. O dashboard reúne as principais informações em um só lugar e torna a análise mais simples de acompanhar.

O projeto pode ser aprimorado futuramente com novas pesquisas, dados mais recentes e informações que permitam comparações ainda mais precisas entre as redes sociais.
